OA 付款审核插件 · 共享盘安装

选择共享盘插件文件夹，刷新 OA 后开始审核

适用于 Chrome 或 Edge 的开发者模式安装。插件已经放在财务部共享硬盘里，安装时只需要在“选择文件夹”的窗口定位到 OA审批插件 这个文件夹本身。

看安装步骤 看使用方法

插件文件夹

版本 0.1.1
日期 2026-04-17
安装方式 加载共享盘文件夹
适用浏览器 Chrome / Edge

插件文件夹路径：\\10.1.0.230\财务部\总账组\OA审批插件

这个文件夹第一层包含插件文件和依赖目录。普通资源管理器里可以看到 manifest.json、background.js、content.js；浏览器的“选择文件夹”窗口只显示文件夹，看不到这些文件是正常的。

安装前准备

先确认电脑能访问共享盘路径 \\10.1.0.230\财务部\总账组\OA审批插件。如果打不开，请先连接公司内网或处理共享盘权限。

插件需要访问公司 OA、内网接口和发票图片域名。安装前请确认浏览器已经能正常打开 http://oa.cyou-inc.com/。

安装步骤

  1. 打开扩展管理页

    在地址栏输入 chrome://extensions。Edge 用户输入 edge://extensions。

  2. 打开开发者模式

    打开页面右上角的“开发者模式”。页面上会出现“加载已解压的扩展程序”按钮。

  3. 点击加载按钮

    点击“加载已解压的扩展程序”。浏览器会弹出一个“选择插件文件夹”的窗口。

  4. 粘贴共享盘路径

    在文件夹选择窗口的地址栏粘贴 \\10.1.0.230\财务部\总账组\OA审批插件，按回车进入该文件夹。

  5. 选中当前文件夹

    地址栏停在 OA审批插件 时，窗口里通常只会显示 assets、bg、node_modules、page、shared 这些子文件夹。不要双击进入任何子文件夹，直接点击“选择文件夹”。

  6. 刷新 OA 页面

    回到 OA 列表页或付款详情页，刷新页面。详情页应出现审核面板，列表页应出现“自动审核”列和“自动审核本页”按钮。

更新已有安装

共享盘更新后

管理员把新版本放进共享盘后，用户只需要进入 chrome://extensions，点击“OA 付款审核”卡片上的刷新按钮，再重新打开 OA 页面。

路径变更时

如果共享盘路径发生变化，先在扩展管理页移除旧扩展，再按安装步骤重新加载新的插件文件夹。

不要把共享盘文件夹复制到本地后再加载。复制到本地会变成一份静态旧版本，后续共享盘更新不会自动同步到浏览器。

日常使用

单张付款单审核

打开 OA 付款详情页，右侧会出现“OA 付款审核”面板。点击“开始采集”，等待状态从“分析中...”变为已完成。

查看主结论

优先看“三项主核对”：金额、收款方、银行账号。绿色“通过”表示匹配，黄色“预警”需要人工确认，红色“异常/失败”需要重点排查。

查看关联证据

继续看“关联单据核对”“合同摘要”“页面采集结果”和“已发现外部来源”。这些区域用于核对 PR、采购订单、验收单、合同和附件证据。

面板操作

面板可以拖动位置；左侧快捷入口可跳转到不同区块；“全部收起”适合先扫总览，需要细看时再展开上下文和诊断信息。

批量审核

  1. 进入付款列表

    打开 OA 待办付款列表，插件会在表格中新增“自动审核”列，并在表格上方显示当前页付款单数量。

  2. 审核整页

    点击“自动审核本页（N）”。插件会按受控并发逐条读取和分析，按钮会变成“审核中...”。

  3. 查看行状态

    每行会从“待审核”进入“正在读取/正在分析”，最终显示“通过”“预警”“异常”“失败”或“不支持”。

  4. 打开结果弹层

    点击某一行的状态按钮，可以查看该付款单的自动审核结果、主核对项和关联单据摘要。

  5. 单独重跑

    如果只想审核某一张付款单，直接点击该行状态按钮即可单独触发审核，不必审核整页。

  6. 处理不支持

    当前批量入口主要面向待办列表。已办列表如果显示“不支持”，通常是因为列表元数据反查不到，不代表付款详情页一定无法单张审核。

常见问题

提示“清单文件缺失或不可读”

通常是选错目录。请重新加载 \\10.1.0.230\财务部\总账组\OA审批插件 这个文件夹本身；在选择窗口里只看到子文件夹是正常的，不要进入它们。

列表页没有自动审核入口

先刷新 OA 页面，再确认扩展已启用。已办列表如果仍提示“不支持”，可能是当前版本还走待办列表反查链路。

OCR 或合同读取失败

确认网络能访问附件和发票图片域名。共享盘文件夹已经包含 assets/tessdata 和必要的 node_modules，不要手动删减依赖目录。

浏览器提示开发者模式风险

这是开发者模式加载本地扩展时的正常提醒。仅从可信共享盘加载插件，不安装来源不明的扩展。
